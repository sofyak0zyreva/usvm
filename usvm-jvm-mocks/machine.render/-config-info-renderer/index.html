ConfigInfoRenderer

class ConfigInfoRenderer(mockConfigInfo: UTestMockConfigInfo, test: UTest, classRenderer: JcUnsafeTestClassRenderer, importManager: JcImportManager, identifiersManager: JcIdentifiersManager, cp: JcClasspath, name: SimpleName, annotations: List<AnnotationExpr>, unsafeUtilsRenderer: JcUnsafeUtilsRenderer) : JcUnsafeTestRenderer

ConfigInfoRenderer inherits JcUnsafeTestRenderer and handles rendering Mockito.when(..).thenReturn(..) Java code. It uses JcExprUsageVisitor for the purpose of creating a variable if some value is repeatedly used in the configuration.
